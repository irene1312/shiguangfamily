# 拾光 · 家庭相册

家庭三人共享相册的移动端 UI 交互原型。

## 体验

打开 `index.html` 或启用 GitHub Pages 后访问网站。

## 当前阶段

这是纯前端演示，不连接微信、云数据库或真实云存储。示例照片采用 CSS 渐变占位；上传选择的本地图片仅作预览，演示照片记录仅保存在当前页面内存，刷新即消失。页面展示的空间额度仅为示例，不代表实际免费额度。

已实现基础导航、照片详情、编辑、相册创建、搜索、上传选择预览、归档状态和订阅开关的演示交互。多相册归属、可靠的文件哈希去重、批量管理、永久存储和完整动画仍待实现。

**请勿上传真实私人家庭照片到公开仓库。**
